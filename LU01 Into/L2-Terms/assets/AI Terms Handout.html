AI Terms Handout

Artificial Intelligence

Machines acting in a way that simulates or mimics human intelligence.

Algorithm

A set of rules a machine can follow to learn how to do a task.

Autonomous

A machine or system that can perform tasks without needing human intervention.

Data Science

An interdisciplinary field that uses statistics, computer science, and information science to solve problems involving data.

Computational Learning Theory

The area of artificial intelligence focused on creating and analyzing machine learning algorithms.

Machine Learning

A subset of AI in which algorithms learn and improve from data without being explicitly programmed for every step.

Deep Learning

A type of machine learning that uses layered networks to learn patterns from data in a way inspired by the human brain.

Supervised Learning

A form of machine learning in which the model is trained on labeled data, where inputs are paired with correct outputs.

Unsupervised Learning

A form of training where the model looks for patterns in data that do not include labels or correct answers.

Reinforcement Learning

A method of training AI by setting goals and rewarding successful actions, encouraging the model to test different strategies.

Dataset

A collection of related data points, usually organized in a consistent structure with labels or attributes.

Training Data

The data used to teach a machine learning model.

Test Data

Data used to check whether a model can perform its assigned task on new or unseen examples.

Bias

An assumption or simplification in a model that can distort learning and lead to inaccurate results if it is too strong.

Overfitting

A condition in which a model learns the training examples too specifically and struggles to perform on new data.

Chatbot

A program designed to communicate with people through text or voice in a way that mimics human conversation.

Bounding Box

A box drawn around an object in an image or video to help a model identify and label it.

General AI (Strong AI)

A type of AI that could perform any intellectual task a human being can do.

Weak AI (Narrow AI)

A model designed for a limited range of tasks, which describes most AI systems currently in use.

Turing Test

A test developed by Alan Turing to determine whether a machine can pass as a human in conversation and behavior.

Neural Processing Unit (NPU)

A specialized processor designed to accelerate AI workloads, especially neural networks.
