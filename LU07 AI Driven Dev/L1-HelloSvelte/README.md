# Svelte Lecture 1

Today we will start learning [Svelte](https://svelte.dev).
Download [Node.js](https://www.nodejs.org) if students don't have it.
I recommend watching [svelte in 100 seconds](https://www.youtube.com/watch?v=rv3Yq-B8qp4).
The only prerequisite to learning svelte is [Node.js](https://nodejs.org/en) and an IDE.
If you are using [VSCode](https://code.visualstudio.com/) I recommend you download
this [extension](https://marketplace.visualstudio.com/items?itemName=svelte.svelte-vscode).

## Creating the project

```bash
# create a new project
npx sv create helloworld
# cd into the project directory
cd helloworld
# install dependencies
npm install
# start the development server
npm run dev
```

Choose the `SvelteKit minimal` template. Add tailwindcss with no plugins.
