# Model Customization with Prompt Engineering

## Prerequisites

- Docker and Docker Compose installed

## What Are We Actually Doing?

**We are NOT fine-tuning a model** (that would require changing the model's weights with training data).

Instead, we're doing **prompt engineering** - creating a specialized AI assistant by giving a pre-trained model very specific instructions about how to behave.

Think of it like hiring a general assistant and giving them a detailed job description to become an email marketing specialist.

We will be doing this by creating a Ollama ModelFile.
Read here about [ModelFile](https://ollama.readthedocs.io/en/modelfile/)

## Demo: Email Subject Line Generator

We'll create a specialized model that generates compelling email subject lines.

## Step 1: Verify Setup

Check that Ollama is running:

```bash
docker ps
```

You should see the `ollama` container running. Verify web UI at: http://localhost:3000

## Step 2: Install Base Model

```bash
# Enter the Ollama container
docker exec -it ollama bash

# Download a small, fast model
ollama pull qwen2.5:0.5b

# Quick test (type /bye to exit)
ollama run qwen2.5:0.5b "Write an email subject line for a sale"

# Exit the container
exit
```

## Step 3: Download the Modelfile

The `Modelfile` is the secret sauce - it contains instructions that turn our general model into an email marketing specialist.

Download the `Modelfile` to your computer.


## Step 4: Transfer Modelfile to Docker and Create Model

First, find where the Modelfile downloaded.
Once you find it, copy it into the Docker container:

```bash
# Navigate to where you downloaded the Modelfile (replace ~/Downloads if needed)
cd ~/Downloads

# Copy the Modelfile into the container
docker cp Modelfile ollama:/tmp/Modelfile

# Enter the container
docker exec -it ollama bash

# Create your specialized model
cd /tmp
ollama create email-guru -f Modelfile

# Verify it was created
ollama list

# Exit container
exit
```

## In Summary

1. **Base Model**: `qwen2.5:0.5b` provides language understanding
2. **Modelfile**: Contains expert instructions that guide behavior
3. **Your Input**: Email content you want subject lines for
4. **Output**: 3 professionally crafted subject line options
