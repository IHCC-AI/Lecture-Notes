# Lecture Notes

This repository contains lecture notes for IHCC CIS 114 Introduction to AI.

## How to Get a Copy

In the directory you want your notes, run:

```bash
git clone https://github.com/IHCC-AI/Lecture-Notes.git
```

## Learning Units Outline

| Learning Unit           | Description                                                                                                                 |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| LU01 — Into             | Foundations of AI, terminology, setup, ethics, and history.                                                                 |
| LU02 — GenAI Text       | Prompting, practical AI assistants, search workflows, lightweight productivity tasks, and realistic use of free tools.      |
| LU03 — GenAI Multimedia | Audio/video generation, AI content creation, and group project work.                                                        |
| LU04 - Hardware         | PI, virtual machines, CasaOS, and operating system concepts.                                                                |
| LU05 - Deploying AI     | Docker, Ollama......                                                                                                        |
| LU06 - Custom Models    | Customizing a model and using it in a workflow.                                                                             |
| LU07 - Automation tools | n8n workflows, databases, APIs, and human-in-the-loop processes.                                                            |
| LU08 - Machine Learning | Have simple neral networks play games, understand how they work, and learn how to train them.                               |
| LU09 - Machine Vision   | Using AI to analyze images, detect objects, and understand visual data.                                                     |
| LU10 - AI Scripting     | Using AI to write simple scripts to Automate tasks, add features, and debug. Work with CSV, write Bash Scripts to do tasks. |

## Detailed Unit and Lecture List

### LU05 — Deploying AI

1. Docker basics
2. Running local models
3. Running Front End UI for Local AI
4. Running AI harnesses i.e. [OpenCode](https://opencode.ai/).

### LU06 — Custom Models

1. Data and model customization basics
2. Fine-tuning and adaptation
3. Evaluating custom models
4. Choosing when to use custom models

### LU07 — Automation Tools

1. No-code and low-code automation ideas
2. APIs, JSON, and data exchange
3. n8n workflow building
4. Human-in-the-loop review and quality control

### LU08 — Machine Learning Basics

[Like Code Bullet](https://www.youtube.com/@CodeBullet)

1. What machine learning is
2. Data, labels, and training examples
3. Training loop, loss, and model learning
4. Accuracy, validation, and overfitting

### LU09 — Machine Vision

1. Images, pixels, and feature extraction
2. Image classification and object detection
3. Video analysis and visual AI workflows
4. Computer vision project and demo

### LU10 — AI Scripting

1. Using AI to generate scripts
2. Bash and Python automation basics
3. CSV, JSON, and data processing tasks
4. Debugging and capstone-ready automation
